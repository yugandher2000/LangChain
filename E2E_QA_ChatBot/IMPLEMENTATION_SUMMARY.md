## 🚀 How to Use

1. **Run the app:**
   ```bash
   streamlit run app.py
   ```

2. **Enter Groq API Key:**
   - Get it FREE from: https://console.groq.com/keys
   - No credit card required!

3. **Select Model:** Choose from 9 available models including:
   - `OpenAI GPT OSS 120B` - For OpenAI-compatible experience
   - `LLaMA 3.3 70B` - Best all-around model
   - `LLaMA 3.1 8B` - Fastest responses
   - And 6 more options!

4. **Configure Parameters:**
   - Temperature: 0.0-1.0 (creativity)
   - Max Tokens: 100-4096 (response length)

5. **Start Chatting!**
